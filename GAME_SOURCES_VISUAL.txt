  ✓ Manage via admin panel
  ✓ Featured games sections
  ✓ User reviews and ratings
  ✓ Persistent storage


🎮 USAGE IN YOUR APP
───────────────────────────────────────────────────────────────────────────────

  HOMEPAGE:
  ─────────
  1. Try to load featured_games from Supabase
  2. If empty, show top 12 from TOP_GAME_SEEDS
  3. Display hero carousel with game details

  ADMIN PANEL:
  ──────────
  1. Try to load games from admin API (Supabase)
  2. If API fails, load directly from Supabase
  3. If no migrations, show empty (no fallback)
  4. Note: Admin doesn't show TOP_GAME_SEEDS

  STORE BROWSE:
  ─────────────
  1. Try to load from Supabase games table
  2. If empty, use TOP_GAME_SEEDS
  3. Apply search/filter on client
  4. Display paginated results

  GAME DETAIL PAGE:
  ─────────────────
  1. Look up by slug from TOP_GAME_SEEDS
  2. Show full details + system requirements
  3. Display related games from same source

QUICK ANSWER TO YOUR QUESTION:

Q: Where are my store games coming from?
A: lib/top-games.ts - 1,000 games generated from 40 base games

Q: Which folder?
A: lib/ folder, specifically: lib/top-games.ts

Q: Can I edit them?
A: Yes! Edit lines 58-120 in lib/top-games.ts to add/modify games

Q: Can I add more?
A: Yes! Three options:
   1. Edit TOP_GAME_DATA array (40+ games)
   2. Apply Supabase migrations and use admin panel
   3. Bulk import with migration files
